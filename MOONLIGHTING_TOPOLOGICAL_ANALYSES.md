# Comprehensive Topological, Wiring, and Integrative Analyses for Human Moonlighting Proteins Across PPI Networks

This document catalogs all **topological**, **local/meso-scale wiring**, **multiplex/cross-network**, and **integrative biological ("beyond pure topology")** analyses that can be performed on the human moonlighting protein dataset ([`data/allmoon_with_moonlitdb_human.csv`](file:///home/davide/projects/interactome/data/allmoon_with_moonlitdb_human.csv)) across the project's canonical and raw Protein–Protein Interaction (PPI) networks.

For every analysis, we explicitly list:
1. **What already exists in this repository** (active modules in root or ready-to-port functions in [`old_streamlit_app/src/interactome/topology.py`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py)).
2. **What exists in installed Python packages** (`networkx`, `scipy`, `numpy`, `polars`) with exact function signatures.
3. **What exists in external Python packages** (`igraph`, `networkit`, `cdlib`, `leidenalg`, `GraphRicciCurvature`, `goatools`, `scikit-learn`, etc.).
4. **What requires custom code** (with exact mathematical formulations and algorithmic blueprints).

## 3. Local Wiring Patterns, Clustering, & Neighborhood Topology

A classic topological distinction in PPI networks is **"Party Hubs"** (high degree, high clustering $C_v$: obligate complex subunits binding partners simultaneously) vs. **"Date Hubs"** (high degree, low clustering $C_v$: transient regulators/moonlighters binding different partners at different times or compartments).

| Wiring Pattern / Metric | Biological Meaning for Moonlighting | Existing Package / Function | Repo / Custom Code Status |
| :--- | :--- | :--- | :--- |
| **Local Triangle Clustering Coefficient ($C_v$) & Weighted Barrat Clustering** | Moonlighting proteins switching between independent pathways should exhibit **lower $C_v$ than degree-matched complex subunits** (open wedges between distinct functional partners). | • `networkx`: `nx.clustering(G, weight=...)`, `nx.triangles(G)` | **Exists in repo** ([`topology.py`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L499)). Degree-controlled residual ($C_v - \mathbb{E}[C | k_v]$) **requires custom code** (LOESS or degree-bin Z-score). |
| **Square Clustering Coefficient ($C_{4,v}$)** | Measures the fraction of 4-cycles (bi-fans) among a node's neighbors without requiring direct neighbor-neighbor triangles. Crucial in **Y2H (HuRI)** where homotypic/bipartite interfaces form 4-cycles rather than triangles (Lucks et al. / Kovacs et al. *Nature Biotech* 2019 L3 principle). | • `networkx`: `nx.square_clustering(G, nodes=...)` | **Exists in repo** ([`topology.py`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L500)). |
| **Structural Holes: Burt's Constraint ($c_v$), Effective Size ($ES_v$), & Hierarchy** | Sociological structural hole theory applied to PPIs: a moonlighting protein spanning two disconnected functional neighborhoods has **low Burt's constraint ($c_v$)** and **high Effective Size ($ES_v = k_v - \frac{2t_v}{k_v}$)** because its partners are non-redundant. | • `networkx`: `nx.constraint(G, nodes=..., weight=...)`, `nx.effective_size(G, nodes=..., weight=...)` | **Built into `networkx`** (`nx.algorithms.structuralholes`), though `nx.constraint` can be slow on all 15k nodes—**custom vectorized Polars/NumPy implementation** of $ES_v = k_v - \frac{2 \cdot \text{triangles}(v)}{k_v}$ runs in $<10\text{ ms}$! |

## 4. Higher-Order Motifs & Graphlet Degree Vectors (GDV)

Graphlets are small induced non-isomorphic subgraphs ($2$ to $5$ nodes) that capture the exact local wiring geometry around a protein beyond simple degree and triangles (Pržulj *Bioinformatics* 2007; Milenković & Pržulj *Cancer Informatics* 2008).

| Graphlet / Motif Analysis | Biological Interpretation for Moonlighting | Existing Package / Function | Repo / Custom Code Status |
| :--- | :--- | :--- | :--- |
| **Exact 15-Orbit Graphlet Degree Vector (GDV, Orbits $O_0 \dots O_{14}$ across $G_0 \dots G_8$, 2–4 nodes)** | Separates proteins into **Open Path/Star Broker orbits** ($O_2$ open-wedge broker, $O_5$ 4-path relay, $O_7$ 3-star hub center), **Hybrid Bridge-Complex orbits** ($O_9, O_{10}, O_{11}$ paw/tailed-triangle apex & tail), **Bipartite 4-Cycle orbits** ($O_8$), and **Closed Clique orbits** ($O_3$ triangle, $O_{12}, O_{13}$ diamond, $O_{14}$ 4-clique). Moonlighting proteins should be enriched in $O_2, O_7, O_{11}$ relative to $O_{14}$. | • External C++/Python wrappers: `orca` (`pyorca`), `graph-tool.clustering.motifs` | **Already implemented via fast exact custom combinatorial equations in repo:** [`topology._compute_exact_gdv_for_nodes()`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L630-L703) and [`topology.compute_gdv_analysis()`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L706-L872)! ## 5. Meso-Scale Community Structure, Overlapping Modules, & Cartography

Standard community detection partitions every node into *exactly one* community—which fundamentally violates the biology of moonlighting proteins! Both **hard-partition cartography** and **overlapping/fuzzy community detection** are critical here.

| Meso-Scale Analysis | Why It Matters for Moonlighting Proteins | Existing Package / Function | Repo / Custom Code Status |
| :--- | :--- | :--- | :--- |
| **Guimerà–Amaral Functional Cartography ($z_i, P_i$) & 7-Role Taxonomy (R1–R7)** | Maps every protein into Within-Module Degree ($z_i$) and Participation Coefficient ($P_i = 1 - \sum_m (k_{im}/k_i)^2$). Moonlighting proteins are expected to populate **R6 (Connector Hubs / Date Hubs: $z \ge 2.5, 0.30 < P \le 0.75$)**, **R7 (Kinless Hubs: $P > 0.75$)**, and **R3 (Non-Hub Connectors: $z < 2.5, 0.62 < P \le 0.80$)**. | • Community detection in `networkx`: `nx.community.louvain_communities(G)`, `nx.community.greedy_modularity_communities(G)`<br>• External: `leidenalg` + `igraph` | **Already implemented in repo** on augmented subnetworks ([`topology.compute_local_wiring_and_linkers()`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L1077-L1158)). **Custom enhancement recommended:** Run Louvain/Leiden on the *entire global interactome* $G$ first so $z_i$ and $P_i$ reflect true proteome-wide modules rather than just local subgraphs. |
| **Generalized Participation Coefficient / Community Entropy ($H_i = -\sum_m \frac{k_{im}}{k_i} \ln \frac{k_{im}}{k_i}$)** | Corrects for community size heterogeneity and counts the **effective number of modules** ($\exp(H_i)$) a moonlighting protein interacts with. | • `scipy.stats.entropy` on module neighbor count vectors | **Requires custom code** (~10 lines of NumPy/Polars on top of `nx.community.louvain_communities`). |
| **Link Community Detection (Ahn, Bagrow & Lehmann *Nature* 2010)** | **The premier meso-scale algorithm for moonlighting proteins:** Instead of clustering *nodes*, it clusters *edges* based on Jaccard similarity of shared neighbors ($S(e_{ik}, e_{jk}) = \frac{|N_+(i) \cap N_+(j)|}{|N_+(i) \cup N_+(j)|}$). Because each edge belongs to a specific functional interaction, **a moonlighting node naturally inherits multiple community memberships** from its incident edges! | • External package: `cdlib.algorithms.hierarchical_link_community` or `igraph` line-graph clustering | **Requires custom code** (or `cdlib`): Easily implemented in ~35 lines of `scipy.sparse` + `scipy.cluster.hierarchy` by computing Jaccard similarity of incident edge pairs sharing a moonlighting vertex $v$ and maximizing partition density $D$. |
| **Clique Percolation Method ($k$-Clique Communities)** | Finds overlapping multiprotein complexes defined by adjacent $k$-cliques sharing $k-1$ nodes (Palla et al. *Nature* 2005). Moonlighting proteins appear in the intersection of $\ge 2$ $k$-clique communities. | • `networkx`: `nx.community.k_clique_communities(G, k=4)`<br>• External: `cdlib.algorithms.kclique` | **Built into `networkx`** (`nx.community.k_clique_communities`). |
| **ego-Splitting / Demon / SLPA Overlapping Community Detection** | **ego-Splitting** (Epasto et al. *KDD* 2017) explicitly splits each node into multiple "persona" nodes based on the connected components of its ego-network, then clusters the personas globally—literally designed to detect multi-persona/moonlighting nodes! | • External packages: `karateclub.EgoNetSplitter`, `cdlib.algorithms.ego_networks`, `cdlib.algorithms.demon`, `cdlib.algorithms.slpa` | Available via `cdlib` / `karateclub`, or **custom code in ~40 lines** using `networkx` (split each node $u$ into persona nodes $u_1, u_2, \dots$ via Louvain on $G[N(u)]$, then run `nx.community.louvain_communities` on the persona graph!). |
| **Core–Periphery Detection (Borgatti–Everett & Rombach Continuous Coreness)** | Tests whether moonlighting proteins form an integrative communication layer between the dense core and specialized periphery. | • External: `cpnet` (`cpnet.BE`, `cpnet.Rombach`) | Requires `cpnet` or **custom code** (rank-ordered degree/coreness profile). |

## 6. Subnetwork Cohesion, Separation, & Null Models

Do moonlighting proteins interact directly with *each other* to form a coordinated "moonlighting subnetwork" (e.g., glycolytic enzymes assembling into a metabolon or apoptotic complex), or are they dispersed uniformly across the interactome as independent sentinels?

| Subnetwork Analysis | What It Tests | Existing Package / Function | Repo / Custom Code Status |
| :--- | :--- | :--- | :--- |
| **Induced Subnetwork Density, Internal Edges ($E_{MM}$), Conductance ($\phi$), & Expansion** | Tests if moonlighting proteins (or specific subsets like `metamoon` or `curated`) form a statistically significant module or have high boundary conductance ($\phi \to 1$, meaning almost all their edges reach outward into the non-moonlighting proteome). | • `networkx`: `nx.density(S)`, `nx.conductance(G, S)`, `nx.normalized_cut_size(G, S)`, `nx.volume(G, S)`, `nx.edge_expansion(G, S)` | **Already implemented in repo:** [`topology.compute_subnetwork_enrichment()`](file:///home/davide/projects/interactome/old_streamlit_app/src/interactome/topology.py#L259-L454). |
